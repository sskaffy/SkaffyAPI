# Test models

Sketchfab models the test plugin imports at startup (`/skaffytest animation model <name>`), to try animation entities with real glTF packages. They are not part of Skaffy's API and don't fall under its LICENSE: each keeps its author's license, listed here and in the `license.txt` inside it. Two are unpacked (folders instead of zips) because their zips are bigger than GitHub allows; the importer reads both.
